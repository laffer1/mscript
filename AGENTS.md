# AGENTS.md — repo workflow rules

- Always deliver changes via a pull request. Workflow: branch off `origin/main`
  (`git checkout -b <topic> origin/main`), commit on the branch, push it
  (`git push -u origin <topic>`), then open the PR with
  `gh pr create --base main --head <topic> ...`.
- Never push commits directly to `main`. No force-push to `main` (or any
  protected branch) without explicit per-case approval.
- Commit messages and PR descriptions end with the attribution trailer of the
  AI agent that actually made the change — never another agent's. Use the
  agent's own standard trailer, for example:
  - Mistral Vibe: `Generated by Mistral Vibe.` +
    `Co-Authored-By: Mistral Vibe <vibe@mistral.ai>`
  - Claude Code: `Co-Authored-By: Claude <model> <noreply@anthropic.com>`
    (PR body: `🤖 Generated with [Claude Code](https://claude.com/claude-code)`)
  - Any other agent: its own `Co-Authored-By:` line naming that agent.
