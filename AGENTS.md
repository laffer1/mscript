# AGENTS.md — repo workflow rules

- Always deliver changes via a pull request. Workflow: branch off `origin/main`
  (`git checkout -b <topic> origin/main`), commit on the branch, push it
  (`git push -u origin <topic>`), then open the PR with
  `gh pr create --base main --head <topic> ...`.
- Never push commits directly to `main`. No force-push to `main` (or any
  protected branch) without explicit per-case approval.
- Commit messages use the Mistral Vibe heredoc suffix
  (`Generated by Mistral Vibe.` + `Co-Authored-By: Mistral Vibe <vibe@mistral.ai>`).
